#  Retail Ecommerce Platform

A full-stack ecommerce web application developed using React.js, Node.js, Express.js, and MySQL that provides a modern online shopping experience with authentication, product management, cart functionality, order tracking, payment simulation, and user dashboard features.

## Features

* User Registration & Login
* Google Authentication using Firebase
* Product Listing & Product Details
* Product Search, Category Filters & Price Sorting
* Shopping Cart Management
* Checkout & Order Placement
* Simulated Payment System
* Payment History Tracking
* Orders Management
* User Profile Dashboard
* Product CRUD Operations
* REST API Integration
* Responsive Modern UI

## Tech Stack

### Frontend

* React.js
* React Router DOM
* Context API
* Axios
* CSS3

### Backend

* Node.js
* Express.js
* MySQL
* JWT Authentication

### Authentication

* Firebase Google Authentication

## Database

* MySQL relational database for users, products, orders, and payments management.

## Project Goal

The objective of this project is to build a complete smart retail ecommerce platform that demonstrates full-stack web development concepts including frontend design, backend APIs, authentication, database integration, CRUD operations, and real-world ecommerce workflow implementation.
